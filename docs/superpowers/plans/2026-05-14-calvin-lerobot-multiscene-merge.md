**Goal:** Add a production LeRobot-compatible merge path for regenerating `datasets/calvin2uam/lerobot_calvin_abcd` from per-scene CALVIN preprocessing outputs, with safe overwrite behavior and optional GR00T stats generation.

**Architecture:** Keep scene splitting and per-scene preprocessing in `runners/preprocess_calvin_multiscene.py`. Add `tools/preprocess/calvin_lerobot_merger.py` as the only merge implementation for LeRobot outputs. Delete the old JSONL-oriented merger and replace its tests with LeRobot fixtures.

**Tech Stack:** Python 3.10, `pathlib`, `json`, `shutil`, `pytest`, `pandas`/`pyarrow` for parquet row remapping, StarVLA `LeRobotSingleDataset` stats helpers, existing CALVIN preprocessing modules.

---

## Target Behavior

Running the multiscene pipeline for ABCD creates one LeRobot dataset at `datasets/calvin2uam/lerobot_calvin_abcd` with:

- one continuous global episode index space;
- one continuous global task index space;
- copied parquet shards under `data/chunk-*/*.parquet`;
- copied MP4 files under `videos/chunk-*/*/*.mp4`;
- merged `meta/info.json`, `meta/episodes.jsonl`, `meta/tasks.jsonl`, `meta/episodes_stats.jsonl`, and `meta/modality.json`;
- root sidecars copied from the first scene and validated across scenes, including `camera_params.json`;
- `meta/stats_gr00t.json` generated by default and skipped with `--skip_stats`;
- default safety: fail if final output already exists, unless `--overwrite` is set;
- per-scene work directories cleared and rebuilt on every run.

    def _rewrite_parquet(
        src_path: Path,
        dst_path: Path,
        episode_map: dict[int, int],
        task_map: dict[int, int],
        frame_start: int,
    ) -> int:
        frame = pd.read_parquet(src_path)
        if "episode_index" in frame.columns:
            frame["episode_index"] = frame["episode_index"].map(episode_map)
        if "task_index" in frame.columns:
            frame["task_index"] = frame["task_index"].map(task_map)
        if "index" in frame.columns:
            frame["index"] = range(frame_start, frame_start + len(frame))
        if "frame_index" in frame.columns:
            frame["frame_index"] = range(frame_start, frame_start + len(frame))
        dst_path.parent.mkdir(parents=True, exist_ok=True)
        frame.to_parquet(dst_path, index=False)
        return len(frame)
    ```

    def _copy_videos(src_root: Path, dst_root: Path, episode_map: dict[int, int]) -> int:
        copied = 0
        for src_path in sorted((src_root / "videos").glob("*/*/episode_*.mp4")):
            local_id = int(src_path.stem.split("_")[-1])
            if local_id not in episode_map:
                continue
            video_key = src_path.parent.name
            global_id = episode_map[local_id]
            dst_path = dst_root / "videos" / "chunk-000" / video_key / f"episode_{global_id:06d}.mp4"
            dst_path.parent.mkdir(parents=True, exist_ok=True)
            shutil.copy2(src_path, dst_path)
            copied += 1
        return copied
    ```

    ```python
    def _copy_validated_sidecars(scene_dirs: Sequence[Path], output_dir: Path) -> None:
        for name in ("camera_params.json",):
            first_path = scene_dirs[0] / name
            if not first_path.exists():
                continue
            first_value = first_path.read_bytes()
            for scene_dir in scene_dirs[1:]:
                candidate = scene_dir / name
                if candidate.exists() and candidate.read_bytes() != first_value:
                    raise SceneDatasetMismatchError(f"Mismatched {name}: {first_path} vs {candidate}")
            shutil.copy2(first_path, output_dir / name)
    ```
